# Archived: the OS-image era of LotusOS

Everything in this folder describes the **retired** LotusOS product: a Debian-based
live/installable ISO with KDE Plasma, Calamares, and VirtualBox verification lanes.

That product direction ended in August 2026. LotusOS is now a local-first developer
workspace runtime (see `docs/architecture.md` and `docs/migration.md`).

These files are kept as historical evidence of what was built and verified during that
phase. They no longer describe the active product and their commands do not apply.

Contents:

- `decisions/` — architecture decision records for Debian base, KDE, and Calamares
- `verification/` — phase-by-phase ISO/VM verification records
- `releases/` — v0.1.0 preview release notes
- `planning/` — the old master plan
- `readme/` — screenshots of the live desktop and old shell surfaces
