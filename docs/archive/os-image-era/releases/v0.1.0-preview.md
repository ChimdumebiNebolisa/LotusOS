# LotusOS Preview v0.1.0

## What is included

- Debian-based LotusOS live/installable ISO source tree built through `live-build`
- KDE Plasma live desktop path
- Lotus Shell autostart in live and installed sessions
- Polished Home dashboard
- Read-only system snapshot and Settings system overview
- Local launcher and bounded resource surfaces
- Calamares installer integration
- Reconciled preview documentation and verification notes

## Verified status

- Phase 4 installer integration: verified
- Phase 5E live-shell verification: verified
- Phase 5F installed-shell verification: manually verified after a Codex automation attempt was blocked by a live-session lock
- Phases 6 through 8: implemented and locally verified
- Phase 9 release hygiene: complete

## Screenshot and evidence summary

- Live-session screenshots are curated into `docs/assets/readme/`
- Full evidence remains under `artifacts/vm-verification/`
- Phase 5E evidence includes live desktop, Home dashboard, and Settings overview screenshots
- Phase 5F includes blocked automation evidence plus manual verification facts supplied by the user

## Build and test summary

- `cd shell/lotus-shell && npm run build`
- `cd shell/lotus-shell/src-tauri && cargo check`
- `cd shell/lotus-shell && npm run tauri build -- --no-bundle`
- `bash os/scripts/build-iso.sh --check`
- `wsl.exe -u root -- /usr/bin/bash os/scripts/verify-iso-contents.sh`
- VirtualBox live ISO verification completed
- Disposable VDI install verification completed, with final Phase 5F success recorded as manual follow-up verification

## Known limitations

- VirtualBox graphics and session instability still appears in some timed runs
- Hardware installation is not verified
- ISO, VDI, VM screenshots, and build logs are not committed to git as release assets by default
- AI Hub remains placeholder/local-first only
- No cloud sync or auth
- No production release guarantees

## What is not included yet

- Production hardware support claims
- Cloud-backed accounts or sync
- Real AI service integrations or bundled credentials
- A committed ISO binary in git history

## Release notes

- The `v0.1.0-preview` tag points to the source-and-docs milestone for this preview
- The ISO asset is not committed to git
- Users can build the ISO locally from the repo using the documented build instructions
- Do not assume the GitHub release includes an ISO asset unless it was intentionally uploaded as part of the release process
