## Fixes Applied

- Replaced unsupported `--image-name` live-build option with supported ISO metadata options.
- Forced Debian mode and Debian mirrors so live-build no longer targets Ubuntu mirrors for Debian `trixie`.
- Added generated live-build config files to `.gitignore` and cleanup.
- Moved live-build execution to `/tmp/lotusos-live-build` to avoid case-insensitive `/mnt/c` filesystem extraction failures.
- Disabled the obsolete trixie security pocket generated by this older live-build version.
- Disabled automatic firmware scanning because this live-build version expects old `Contents-amd64.gz` paths.
- Renamed `spectacle` to Debian's `kde-spectacle` package.
- Set live init packages to systemd.
- Switched from Syslinux to GRUB2 after Debian trixie Syslinux paths failed.
- Switched from `iso-hybrid` to plain `iso` after `isohybrid` was missing.
