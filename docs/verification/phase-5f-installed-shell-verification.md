# Phase 5F: Installed System Shell Verification

Status: planned after Phase 5E live verification.

## Purpose

Install the rebuilt ISO to a disposable VDI and confirm the current Lotus Shell appears after installed login.

## Safety Rules

- Use a newly created disposable VM disk only.
- Never point Calamares at a host disk or any real user disk.

## Checks

- Disposable install completes.
- Installed VDI boots after ISO detach.
- SDDM greeter appears.
- Plasma desktop loads.
- Lotus Shell autostarts with updated surfaces from Phases 5A through 8.

## Evidence To Capture

- Installer completion screenshot.
- Installed boot screenshot.
- Installed desktop screenshot showing updated Lotus Shell.
