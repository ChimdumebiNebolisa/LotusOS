# Logos

Original LotusOS logo assets.

| File | Use |
| --- | --- |
| `lotusos-icon.png` | Square icon (lotus + terminal prompt). Favicon, app icon, SDDM, GRUB, etc. |
| `lotusos-wordmark.png` | Horizontal logo with LotusOS wordmark. Headers, README, installer splash, etc. |

Both files are PNG with transparent backgrounds.
