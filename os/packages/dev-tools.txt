# LotusOS developer tools draft

## MVP Defaults

- Git from Debian repositories.
- Node.js and npm from Debian repositories.
- Python 3 and pip from Debian repositories.
- Rust compiler and Cargo from Debian repositories for the first ISO.
- KDE terminal and editor tools through Konsole and Kate.

## Deferred Choices

- Prefer documenting Docker as a post-install setup until image size and service behavior are tested.
- Prefer documenting VS Code/Codium tradeoffs before adding a non-Debian repository.
- Prefer Debian packages for reproducibility unless a tool is unusably stale for the MVP workflow.
- Do not bundle AI CLI credentials or API keys.
